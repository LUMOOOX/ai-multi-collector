# AI Multi-Collector Universal 🚀

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![GreasyFork](https://img.shields.io/badge/Install-GreasyFork-red.svg)](https://greasyfork.org/scripts/577321)

**AI Multi-Collector** — это универсальный Tampermonkey-скрипт, который значительно упрощает работу с ответами ИИ. Он позволяет выделить сообщение бота и в один клик скопировать все блоки кода, объединяя их в один чистый текстовый фрагмент.

---

✨ Основные возможности
⚡ Мульти-платформенность: Полная поддержка DeepSeek, Gemini и ChatGPT

🖱️ Выделение в один клик: Используйте визуальный режим выбора сообщения или горячие клавиши.

🧹 Умная очистка: Автоматически удаляет «мусорные» заголовки языков программирования (javascript, python и т.д.) при копировании из ChatGPT.

📊 Статус-панель: Отображает количество скопированных блоков и общее число символов.

⌨️ Горячие клавиши:

Ctrl + B — Включить режим выбора (Select).

Ctrl + C — Скопировать код из выбранного блока.

Esc — Сбросить выделение.

---

## 🛠 Установка

1. Установите расширение **Tampermonkey** для вашего браузера.
2. Откройте прямую ссылку на установку:
   👉 [Установить AI Multi-Collector Universal](https://raw.githubusercontent.com/LUMOOOX/ai-multi-collector/main/ai-multi-collector.user.js)
3. Нажмите кнопку **"Установить"** (или "Обновить") во всплывающем окне расширения.

---

## ⚙️ Технические детали

Скрипт написан на чистом JavaScript и использует минимальные ресурсы:
**Автоматическая локализация:** Интерфейс переключается на русский или английский в зависимости от языка системы.
**Поддержка тем:** Дизайн панели адаптируется под светлую или темную тему браузера.
**Безопасность:** Не требует доступа к внешним API, работает локально в вашем браузере.

# Changelog

## [3.0] - 2024

### Добавлено
- 🔢 Нумерация блоков кода с индивидуальной настройкой для каждой платформы
- 🎨 Чистые стили выделения (только пунктирная обводка)
- 🔀 Раздельная логика выделения (нельзя смешивать блоки кода и сообщения)
- 🛡️ Защита от дурака: лимит 50 блоков, проверка элементов
- 🔄 Автосброс выделений при смене URL (переключение чата)
- 🚀 GM_setClipboard для надёжного копирования
- ⌨️ Новая горячая клавиша Ctrl+Shift+R (полный сброс)

### Исправлено
- Исправлена очистка названий языков для всех платформ
- Исправлен пересчёт нумерации после удаления блоков
- Исправлен лимит MAX_BLOCKS (теперь общий для всех выделений)
- Исправлен findFullCodeBlock для ChatGPT (компактная обертка)

### Улучшено
- Повышена прозрачность панели с 0.1 до 0.25 для лучшей видимости
- Добавлена функция isInteractiveElement для предотвращения ложного сброса
